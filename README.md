# Assignment 1 - Builder Pattern (RPG Characters)
## Domain Description
This project implements the Builder design pattern in Java to construct different RPG character types (Warrior, Mage).
## How to Run
1. Clone the repository.
2. Open in IntelliJ IDEA (JDK 17).
3. Run `Main.java`.
## Structure
- `Hero`: Product class
- `HeroBuilder`: Builder interface
- `HeroBuilderImpl`: Base abstract builder
- `WarriorBuilder`, `MageBuilder`: Concrete builders
- `Main`: Client / Demo
